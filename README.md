# Котячья память

Игра на поиск пар с котиками. Учебный проект [RS School](https://rs.school/) — задание Memory Game.

**Деплой:** https://direktor3092.github.io/memory-game/

## О проекте

Классическая игра «мемори» на 16 карточек (8 пар). Игрок открывает по две карточки за ход, пытаясь найти совпадающие изображения. Цель — открыть все пары за минимальное число ходов.

## Возможности

- 16 карточек с фотографиями котов, случайное перемешивание при каждой новой игре.
- Счётчики ходов и найденных пар.
- Модальное окно победы с итоговым числом ходов.
- Таблица лидеров: топ-10 результатов, сохранение в `localStorage`.
- Сортировка: по числу ходов (меньше — выше), при равенстве — по дате (раньше — выше).
- Звуковые эффекты (переворот, совпадение, победа) и фоновая музыка.
- Шипение кота и тряска карточек при серии из 3 промахов подряд.
- Кнопка mute, состояние звука сохраняется между сессиями.
- Адаптивная вёрстка: мобильные, планшеты, десктоп.
- Доступность: навигация с клавиатуры, фокус-стили, `aria-label`, поддержка `prefers-reduced-motion`.

## Стек

- **JavaScript** — ES-модули, без фреймворков.
- **HTML** — генерируется через `document.createElement` (в `<body>` только `<script>`).
- **CSS** — без препроцессоров, на CSS-переменных, размеры в `rem`/`em`.
- **Vite** — dev-сервер и сборщик.

## Локальный запуск

Требуется Node.js 18+.

```bash
git clone https://github.com/direktor3092/memory-game.git
cd memory-game
git checkout memory-game
npm install
npm run dev
```

Открой `http://localhost:5173/` в браузере.

### Сборка

```bash
npm run build     # соберёт в dist/
npm run preview   # локальный просмотр сборки
```

## Управление

- **Мышь** — клик по карточке.
- **Клавиатура** — Tab, Enter/Space для открытия карточки.
- **Escape** — закрытие модального окна.
- **Кнопка 🔊** — вкл/выкл звук.
